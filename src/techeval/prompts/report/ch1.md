# 작성할 부분: 1. 분석 배경 — 서베이 근거 문단

1장의 고정 문단(KV cache 구조, SW/HW 두 갈래, 대상 환경 선정 이유)은 코드가 이미 넣었다. 너는 그 뒤에 이어질 **1~2문단**만 쓴다.

- 입력의 서베이 근거(io_survey / kv_survey)로 "KV cache가 메모리 병목이 되는 구조"와 "SW 축소 / HW 계층 확장 두 접근의 분기"를 뒷받침한다.
- 서베이가 다른 원 출처의 수치를 인용한 경우, 서베이를 통한 2차 인용임을 밝힌다.
- 특정 기술의 평가·판정은 쓰지 않는다(4장에서 다룬다).
