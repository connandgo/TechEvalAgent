# 작성할 절: 4. 관점별 평가 — 한 관점

입력은 한 관점의 기준별 평가 결과(두 기술)다. 이 관점의 평가를 **기술별로** 서술한다.

- 기술마다 굵은 글씨 소제목(예: **DeepSeek-V2 MLA**)을 두고, 기준 순서대로 한 기준당 1~3문장으로 쓴다.
- 각 기준 서술에는 판정 레벨, 판정 이유(content), 신뢰도, 근거 단위(paper/family)를 담고 `[E: …]`를 붙인다.
- 아래 "관점별 판정 방식"에서 요구하는 항목을 빠뜨리지 않는다.
- 마지막에 두 기술의 판정이 이 관점에서 어떻게 다르게 나타나는지 1~2문장으로 정리하되, 차이를 우열이 아니라 근거·단위·기준의 차이로 쓴다.
- 요약표는 코드가 절 말미에 붙인다. 표를 만들지 않는다.
