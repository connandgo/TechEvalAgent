## 관점별 판정 방식 — 도메인 적합성(대규모 데이터센터 장문맥 추론)

- D1 장문맥 병목, D2 동시 처리, D3 지연·에너지·비용: 수치 크기에 등급을 매기지 않는다. 판정은 **우리 도메인 조건과의 직접성**(L3 직접 / L2 간접 / L1 근거 없음)이다.
  - 모든 수치에 측정 조건(모델 규모·컨텍스트·하드웨어·베이스라인·배치)을 병기한다.
  - **L2이면 외삽 논리(details.extrapolation_logic)를 반드시 쓴다.**
  - **L1(근거 없음)이면 수치가 없는 것이 정상이다.** "찾아봤으나 우리 도메인 조건에 대한 수치 근거가 없다"는 판정으로 쓰고, 근거 자체를 찾지 못한 `not_public`(검색어·검색일 표기)과 구분한다.
- D4 변경 범위: 모델 재학습, 모델 변환, 서빙 엔진 수정, HW 교체, 메모리 추가, 기타 6개 항목의 Y/N/unknown(details.checklist)을 모두 쓴다.
- 두 기술의 수치를 서로 비교하지 않는다(서로 다른 실험이다).
