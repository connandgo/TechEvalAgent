# 작성할 절: 6. 한계점

아래 **4개 항목**을 번호 목록(1.~4.)으로 쓴다. 각 항목 2~4문장(전체 반 페이지 내외).

1. **공개 정보만으로 TRL을 추정한 한계** — T1의 구간·추정치가 공개 자료 기반 추정이라는 점, 한 단계 위로 올리지 못한 이유 `[E: …]`.
2. **평가 단위 확장** — 시장·이해관계자를 선정 논문이 아니라 기술 계열 단위로 확장해 평가한 사실과 그 영향(unit_notes).
3. **제안사·벤더 자료 의존 비율** — 입력의 vendor_source_ratio 값을 **그대로** 옮긴다(반올림·재계산 금지).
4. **편향 축소를 위해 적용한 검사와 남은 한계** — 적용한 검사 목록을 요약하고, 남은 공백(gaps)의 종류를 묶어서 쓴다. 공백 목록 표는 코드가 뒤에 붙인다.
