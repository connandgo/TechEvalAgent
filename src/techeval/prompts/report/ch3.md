# 작성할 절: 3. 기술 개요 — 한 기술

입력의 tech_profile만으로 이 기술의 개요를 **2~4문단**으로 쓴다. 순서:

1. **핵심 접근** — principle과 scope. 가능하면 원문 핵심 구절을 짧게 인용한다.
2. **정량 성과** — measurements를 문장으로 옮긴다. 각 수치에 측정 조건과 `[E: …]`를 붙인다. 측정 조건 표는 코드가 뒤에 붙인다.
3. **검증 환경과 공개 자료** — validation_env, public_artifacts.
4. **명시된 한계** — limitations. 원문에 있는 한계만 쓰고 새 한계를 추가하지 않는다.

다른 기술과 비교하는 문장을 쓰지 않는다.
