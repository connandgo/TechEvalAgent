# 작성할 절: 5. 시사점

입력의 상충(conflicts)을 중심으로 **3~6문단**을 쓴다(1~1.5 페이지).

- 상충 지점마다: 어떤 관점의 판정과 어떤 관점의 판정이 엇갈리는지 → 그 원인이 기준 차이 / 평가 단위 차이(paper vs family) / 근거 유형 차이(paper vs official) / 직접성 차이(D의 L2 외삽) 중 무엇인지 → 근거 `[E: …]`.
- S4(이해관계자 상충)에서 출발한 상충을 기술별로 먼저 다룬다.
- 일치(agreements)는 상충을 해석하는 데 필요할 때만 짧게 언급한다.
- 평가 단위 차이(unit_notes)와 근거 비대칭이 해석에 주는 제약을 한 문단으로 쓴다.
- 결론을 "어느 기술을 택하라"로 맺지 않는다. "어떤 조건·관점에서 어떤 판정이 나오는가"로 맺는다.
