# D1 — 장문맥 병목

대상 기술 tech_id: {tech_id}

**평가 질문**: KV cache 부담이 얼마나 감소하거나 어느 계층으로 이전되는가?

"감소"와 "이전"을 구분해서 본다. 캐시 자체가 줄어드는 것과, 크기는 그대로인 채 다른 메모리 계층으로 옮겨 가는 것은 서로 다른 결과다. 근거가 가리키는 쪽을 그대로 쓴다.

판정은 시스템 프롬프트의 D1~D3 공통 판정 방식(L3/L2/L1)을 따른다.

## 출력

- `level` — `"L1"` / `"L2"` / `"L3"`
- `details.directness` — `level`과 동일
- `details.extrapolation_logic` — L2일 때 필수
- `measurements` — 이 판정에 쓰인 모든 수치. 최소 1건 필요하다.
- `content` — 한국어 2~4문장
