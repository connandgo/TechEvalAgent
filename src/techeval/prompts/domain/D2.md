# D2 — 동시 처리

대상 기술 tech_id: {tech_id}

**평가 질문**: 배치 크기·동시 세션·생성 처리량에 어떤 영향을 주는가?

이 기준의 핵심 조건은 **다중 요청**이다. 배치 크기 1에서만 측정된 결과는 우리 도메인(다중 요청)에 직접 근거가 되지 않는다. 배치 크기·동시 세션 수가 원문에 명시돼 있는지 확인하고, 명시돼 있지 않으면 `measurements`의 `batch_size`를 비우고 `condition_note`에 "원문 미기재"라고 적는다.

판정은 시스템 프롬프트의 D1~D3 공통 판정 방식(L3/L2/L1)을 따른다.

## 출력

- `level` — `"L1"` / `"L2"` / `"L3"`
- `details.directness` — `level`과 동일
- `details.extrapolation_logic` — L2일 때 필수
- `measurements` — 최소 1건. 처리량 수치에는 배치 크기를 가능한 한 채운다.
- `content` — 한국어 2~4문장
