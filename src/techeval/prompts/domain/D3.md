# D3 — 지연·에너지·비용

대상 기술 tech_id: {tech_id}

**평가 질문**: TTFT/TPOT, 토큰당 에너지, 전송 오버헤드, 총비용 근거가 있는가?

네 가지(지연 / 에너지 / 전송 오버헤드 / 총비용)를 각각 확인한다. 일부만 있으면 있는 것만 기록하고, 없는 항목은 `content`에 "공개 자료에서 확인되지 않음"으로 명시한다. 없는 항목을 다른 항목의 수치로 대신하지 않는다.

판정은 시스템 프롬프트의 D1~D3 공통 판정 방식(L3/L2/L1)을 따른다.

## 출력

- `level` — `"L1"` / `"L2"` / `"L3"`
- `details.directness` — `level`과 동일
- `details.extrapolation_logic` — L2일 때 필수
- `measurements` — 최소 1건
- `content` — 한국어 2~4문장
