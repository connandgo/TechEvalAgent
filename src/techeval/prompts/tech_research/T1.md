# T1 — 현재 TRL

대상 기술 tech_id: {tech_id}

**평가 질문**: 공개 근거로 확인 가능한 가장 높은 단계는 어디인가?

**판정 방식** (docs/CRITERIA.md §2.1): TRL 1-3 / 4-6 / 7-9 구간 + 구간 내 추정치. "공개 정보 기반 추정" 표기, 인용 근거, **한 단계 위로 올리지 못한 이유** 필수 기재.

TRL 참고 구간:
- **1-3** 기초 원리·개념·실험적 검증 (해석 또는 시뮬레이션)
- **4-6** 실험실~관련 환경에서 구성요소/시스템 검증 (시제품)
- **7-9** 실제 운용 환경 시연~실서비스 운영

## 출력

- `level` — `"TRL 1-3"` / `"TRL 4-6"` / `"TRL 7-9"` 중 하나.
- `level_estimate` — 구간 내 추정치. 반드시 "공개 정보 기반 추정"이라는 문구를 포함한다. 예: `"TRL 5 (공개 정보 기반 추정)"`
- `details.trl_band` — `"1-3"` / `"4-6"` / `"7-9"`
- `details.estimate` — 구간 내 추정 단계 정수
- `details.why_not_higher` — **한 단계 위 구간으로 올리지 못한 이유.** 어떤 근거가 공개돼 있지 않아서 올리지 못했는지 구체적으로 쓴다. 비워 두면 안 된다.
- `content` — 한국어 2~4문장.
