# T3 — 재현성

대상 기술 tech_id: {tech_id}

**평가 질문**: 코드, 모델/설계, 평가 스크립트·데이터, 제3자 재현이 공개됐는가?

4개 항목 각각을 `Y` / `N` / `unknown` 으로 판정한다.

| 항목 | 무엇을 확인하나 | Y 조건 |
|---|---|---|
| `code` | 구현 코드가 공개돼 있는가 | 접근 가능한 저장소·배포본에 이 기술의 구현이 있음 |
| `model_or_design` | 모델 가중치 또는 하드웨어 설계가 공개돼 있는가 | 가중치 배포 또는 설계 명세 공개 |
| `eval_scripts_data` | 논문 수치를 재현할 평가 스크립트·데이터가 공개돼 있는가 | 평가 하네스 또는 데이터셋이 접근 가능 |
| `third_party_reproduction` | 원저자가 아닌 제3자의 구현·재현이 있는가 | 원저자 저장소 **밖에서** 독립적으로 구현·검증된 사례 |

판정 기준:
- 근거가 "공개돼 있다"를 가리키면 `Y`.
- 근거가 "공개돼 있지 않다" 또는 "파트너·심사를 거쳐야 접근 가능하다"를 명시하면 `N`.
- 어느 쪽 근거도 못 찾았으면 `unknown`. **찾지 못한 것을 `N`으로 적지 않는다.**

**`level`을 네가 정하지 않는다.** 레벨은 위 4항목 결과로 코드가 계산한다. 너는 체크리스트와 근거, 서술만 만든다.

## 출력

- `checklist` — 위 4개 키 각각 `Y`/`N`/`unknown`
- `urls` — 항목별 근거 URL (있는 것만)
- `content` — 한국어 2~4문장. 무엇이 공개돼 있고 무엇이 확인되지 않는지.
- `citations` — 각 판정의 근거
