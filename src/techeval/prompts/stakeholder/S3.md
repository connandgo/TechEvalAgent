# S3 — 부담

대상 기술 tech_id: {tech_id}
criterion_id: S3

**평가 질문**: 도입 비용, 전환 부담, 기존 사업과의 충돌은 무엇인가?

## 판정 방식 (docs/CRITERIA.md §2.3)

**4주체 각각 최소 1개**를 적는다. 하나라도 비면 결과가 폐기된다. 증거 규칙은 S2와 같다.

부담은 비용만이 아니다. 전환에 드는 검증 공수, 기존 제품·사업과의 충돌, 회수 시점의 불확실성도 부담이다.

## 출력

- `level` — 항상 `"narrative"`
- `details.burdens` — 4주체 id를 키로, 값은 항목 리스트. 각 항목은 `text`(한국어 한 문장), `evidence_id`, `is_inference`
- `content` — 한국어 2~4문장. 어느 주체가 직접 자료로 확인됐고 어느 주체가 추론인지가 드러나야 한다.
- `citations` — 근거
