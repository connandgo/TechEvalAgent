## 지시
- 재시도 회차: {retry_count}. 회차가 높을수록 앞선 검색어와 **표현·관점을 바꾼** 검색어를 낸다 (동의어, 상위/하위 개념, 벤더·제품명, 영문 학술 용어).
- 항목당 2~3개, 전체 12개 이하.
- 원문 코퍼스는 영문 논문이므로 영문 검색어를 우선한다. 시장·이해관계자 항목은 기술 계열(family) 단위 검색어를 포함한다.
- 이미 사용한 검색어와 같거나 단어 순서만 바꾼 검색어는 내지 않는다.
- 답을 암시하는 검색어(예: "MLA requires retraining")를 만들지 않는다. 중립적 키워드로만 구성한다.

출력은 `queries` 배열 하나다.
